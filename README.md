# 玄域 - 英语六级学习平台

一个基于 **Next.js 16** 构建的现代化英语学习平台，专注于六级考试备考和词汇学习。

## ✨ 特性亮点

### 📚 词汇学习
- **智能记忆算法**：基于 SM-2 间隔重复算法，自动安排复习计划
- **卡片学习模式**：3D 翻转卡片，支持发音播放
- **测验系统**：选择题、拼写题、混合模式多种测验方式
- **数据可视化**：学习趋势、记忆曲线、热力图等多维度统计
- **游戏化系统**：等级、成就、XP 经验值、连续打卡
- **专注模式**：内置番茄钟，提升学习效率

### 📝 六级考试
- **真题模拟**：包含 2025 年 6 月和 12 月多套真题
- **阅读理解**：支持文章阅读、题目作答、答案解析
- **写作翻译**：在线写作和翻译练习
- **进度追踪**：实时显示答题进度和正确率

### 🎨 界面设计
- **现代 UI**：采用 shadcn/ui 组件库，简洁美观
- **暗黑主题**：默认深色模式，护眼舒适
- **流畅动画**：Framer Motion 驱动的平滑过渡效果
- **响应式布局**：完美适配桌面和移动设备

## 📖 使用指南

### 词汇学习

1. 访问 `/vocabulary` 进入词汇学习页面
2. 选择"学习新词"或"复习旧词"模式
3. 使用卡片学习：
   - 点击卡片或按空格键翻转
   - 使用 1-4 键评分（忘了/模糊/认识/太简单）

4. 切换到"测验"标签进行测验练习

1. 访问 `/cet6` 进入考试页面
2. 选择一套试卷开始练习
3. 答题说明：

   - 写作和翻译题在线作答
   - 完成后可查看最终得分

## 🧠 核心算法

### SM-2 间隔重复算法

词汇学习模块采用经典的 SM-2 算法，根据用户记忆情况动态调整复习间隔：

```typescript
// 难度系数更新公式
EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))

// 复习间隔规则
- 第 1 次通过：1 天后复习
- 第 2 次通过：3 天后复习
- 第 3 次通过：6 天后复习
- 之后：间隔 = 上次间隔 × 难度系数
```

### 游戏化系统

- **等级系统**：10 个等级，每 100 XP 升一级
- **成就系统**：10 项成就，涵盖学习、测验、专注等多个维度
- **连续打卡**：记录每日学习，维护学习连续性

## ❓ 常见问题

### Q: 端口被占用怎么办？

```bash
# 使用其他端口启动
npx next dev -p 3001
```

### Q: 安装依赖报错？

```bash
# 清除缓存重新安装
rm -rf node_modules package-lock.json
npm install
```

### Q: 学习进度会丢失吗？

学习数据保存在浏览器 localStorage 中，清除浏览器数据会导致进度丢失。建议定期备份。

### Q: 如何添加新单词？

编辑 `src/lib/vocabulary-data.ts` 文件，按格式添加新的单词对象。

## 📝 开发指南

### 代码规范

- 使用 TypeScript 严格模式
- 遵循 ESLint 规则
- 组件采用函数式编程风格
- 使用自定义 Hooks 提取复用逻辑

1. 在 `src/app/` 下创建新的路由目录
2. 在 `src/components/` 下创建对应组件
3. 在 `src/lib/` 下添加工具函数
4. 更新导航栏菜单

- 使用 Turbopack 加速开发构建
